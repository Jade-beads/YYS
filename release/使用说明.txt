YYS.exe 使用说明(Windows)
========================

这是免安装的单文件程序:把 YYS.exe 和 config.ini 放在同一个文件夹里,双击 YYS.exe 即可。
首次启动要解压内置文件,会慢十几秒。

【两种用法,二选一】

A. 安卓模拟器(推荐,游戏可以放后台,不占鼠标)
   1. 装 MuMu模拟器 或 雷电模拟器,在里面装好阴阳师并登录。
   2. 打开 YYS.exe,点「连接ADB」。
      - 装在默认路径的 MuMu 会弹框问端口:第一个实例填 16384(多开每个 +32,以 MuMu「问题诊断」里显示的为准)。
      - 雷电会自动识别。
   3. 日志出现「监测到ADB设备」才算连上。脚本会把模拟器分辨率改成 1136x640,画面变糊是正常的。
   4. 用完点「断开ADB」,分辨率会复原。脚本运行期间不要重启模拟器。

   没有自动连上时(日志出现「未检测到ADB设备」,或者弹了窗):
   - 弹窗「选择 adb.exe」:到模拟器的安装目录里找 adb.exe 选中它(MuMu 在安装目录的 shell 文件夹里,雷电在安装目录根目录)。
   - 弹窗「模拟器ADB地址」:填模拟器的地址。MuMu 默认 127.0.0.1:16384,多开每个 +32;雷电一般不用填,直接取消。
   - 不想每次弹窗,把这两项写进 config.ini(等号后面填,例子):
       adb_path=D:\Program Files\Netease\MuMuPlayer-12.0\shell\adb.exe
       adb_address=127.0.0.1:16384
   - 电脑上如果还装了别的 adb(比如 Android SDK 的),两个版本会互相踢掉对方,设备会时断时连。用模拟器自带的那份。

B. 官方桌面版客户端(游戏必须在最前面,脚本会占用你的鼠标)
   1. 右键 YYS.exe ->「以管理员身份运行」(否则点击发不进游戏)。
   2. 游戏分辨率用原始的 1136x640,窗口拖到主屏幕的左上角。
   3. 不要点「连接ADB」,直接选任务点「开始」。

【每次开始前】
   - 脚本不会自己进副本:先手动把游戏点到对应界面(例如御魂的挑战页),配好阵容,再点「开始」。
   - 选对任务:单人刷御魂选「4 御魂/御灵/契灵探查(单刷)」;「2 司机」「3 打手」是两个号组队用的。
   - 次数框默认是 200 或 inf,记得改成你要的次数。
   - 游戏设置里关掉「战斗结算个性化」,否则会卡在结算界面。
   - 如果点了「开始」没反应:多半是游戏没停在该任务认识的界面上,脚本此时不会有任何提示。
   - 「15 个人突破(打8退N)」:先手动进到个人突破的结界板再开始。板上只剩最后一个结界时,脚本会进攻后马上退出
     N 次(退出算失败,用来压结界等级),然后再正常打掉它。N 在 config.ini 的 [tupo] tui= 里改,默认 4。
     「次数」按进攻次数算,退出的那几场也算在内。

【其它】
   - config.ini 里 Nthread 是标签页数量(= 同时操作几台设备),debug 请保持 False。
   - Windows 安全中心 / 杀毒软件可能会拦截或误报(未签名的 PyInstaller 程序很常见),需要手动放行。
   - 模板图片是打包时内置的;游戏更新导致按钮认不出来时,需要用新源码重新打包。
   - 网易用户协议禁止第三方脚本,有封号风险,建议先用小号。
